# Mini-project

This year's summer school includes a session on Thursday afternoon in which
attendees will form groups to work on one of several predefined mini-projects.
This course has a mini-project associated with it, which involves differentiable
programming for two 'toy' models. These models represent elements of earth
system dynamics but are conceptually simple enough to experiment with in a
mini-project.

Toy models are available in the following Jupyter notebooks, which include some
initial code and ideas for investigation:

* [Lorenz '96](lorenz96.ipynb)
* [Linear shallow water](shallow_water.ipynb)
